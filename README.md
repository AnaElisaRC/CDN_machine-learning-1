🤖 Aprendizado de Máquina (Machine Learning)

Este repositório reúne os materiais de aula, resumos, cadernos práticos em Jupyter Notebooks e arquivos de acompanhamento da disciplina de Aprendizado de Máquina do curso de Tecnologia em Ciência de Dados para Negócios da FATEC Votorantim.

O conteúdo abrange desde conceitos introdutórios e pré-processamento de dados até algoritmos clássicos e avançados de Machine Learning, tais como Regressão Linear, Regressão Logística, Máquinas de Vetor de Suporte (SVM), Árvores de Decisão, Métodos Ensemble e Florestas Aleatórias, Redução de Dimensionalidade, Clusterização e Introdução a Redes Neurais.
